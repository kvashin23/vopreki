# Сайт академии «Вопреки»

Многостраничный статический сайт спортивной академии «Вопреки» (Краснодар): падел, футбол, большой теннис, плавание, функциональный зал.

У каждой страницы свой адрес:

| Адрес | Страница |
|---|---|
| `/` | Главная |
| `/padel/`, `/football/`, `/tennis/`, `/swim/`, `/gym/` | Направления: преимущества, расписание, цены, тренеры |
| `/services/` | Услуги и аренда |
| `/news/`, `/news/<slug>/` | Новости и отдельные статьи |
| `/contacts/` | Контакты и запись |
| `/privacy/`, `/consent/`, `/ads-consent/` | Политика обработки ПДн и согласия |
| `404.html`, `sitemap.xml`, `robots.txt` | Служебные файлы |

HTML собирается заранее, поэтому весь текст виден поисковикам и превью ссылок в мессенджерах. JavaScript отвечает только за интерактив: слайдер, фильтры расписания, окна записи и тренеров.

## Структура

```
src/data.js        ← весь контент: направления, цены, расписание, тренеры, новости, контакты
src/render.js      ← шаблоны страниц (генерируют HTML)
src/legal/         ← юридические документы: .docx и сгенерированные из них .js
assets/css/        ← стили
assets/js/main.js  ← интерактив на страницах
assets/fonts, img  ← шрифт Phonk, текстура, логотип, favicon; img/uploads — все фото сайта
assets/docs/       ← .docx документов для скачивания
tools/serve.ps1    ← локальный сервер (PowerShell, ничего ставить не нужно)
tools/build.html   ← сборка сайта из браузера
tools/build.mjs    ← сборка через Node.js
tools/docx2html.ps1 ← конвертер .docx → HTML для юридических страниц
index.html, padel/, … ← готовые страницы (результат сборки, их не правят руками)
```

## Как посмотреть локально

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File tools/serve.ps1
```

Затем откройте http://localhost:5173.

## Как поменять контент

1. Отредактируйте `src/data.js`: цены, расписание, тренеров, новости, телефон.
2. Пересоберите сайт одним из способов:
   - **Без Node:** запустите `tools/serve.ps1` и откройте http://localhost:5173/tools/build.html → «Собрать сайт».
   - **С Node.js 18+:** выполните `node tools/build.mjs` или `npm run build`.
3. Закоммитьте изменения: исходники и пересобранные страницы.

Если нужна новая новость, добавьте строку в `NEWS_RAW`, абзацы в `NEWSTXT` и адрес в `NEWS_SLUGS`. Новость сама появится в списке, на главной и в `sitemap.xml`.

## Форма записи

По умолчанию заявка открывает письмо на `vopreki.academy@gmail.com`. Чтобы заявки приходили автоматически, например в Telegram или CRM, укажите адрес обработчика в `SITE.formEndpoint` (`src/data.js`) и пересоберите сайт. Форма отправляет `POST` с JSON `{ dir, name, phone, page }`.

Токен Telegram-бота нельзя класть в файлы сайта: его увидит любой посетитель. Нужен серверный обработчик, например облачная функция.

## Публикация

Подойдёт любой статический хостинг: свой сервер с nginx, GitHub Pages, Netlify, Yandex Object Storage. Загружается вся папка, кроме `src/` и `tools/`, хотя они ничему не мешают.

- `404.html` рассчитан на сайт в корне домена (`<base href="/">`).
- Адрес сайта для `canonical`, Open Graph и `sitemap.xml` задаётся в `SITE.url`.


## Юридические документы

Страницы `/privacy/`, `/consent/` и `/ads-consent/` собираются из файлов `src/legal/*.docx`. На каждой странице есть кнопка «Скачать .docx», файлы для неё лежат в `assets/docs/`. Если документ изменился, замените `.docx` в обеих папках и выполните:

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File tools/docx2html.ps1 -Docx src/legal/privacy.docx -Out src/legal/privacy.js -Skip 1
```

Для `consent` и `ads-consent` используйте `-Skip 2`: столько первых абзацев занимает заголовок. После этого пересоберите сайт.

## Аналитика и cookie

На сайте подключена Яндекс.Метрика, тот же счётчик, что на старом сайте (`SITE.metrika`). Она загружается только после нажатия «Принять» в cookie-баннере. Так требует Политика, где сказано, что согласие на cookie даётся через баннер. Выбор посетителя запоминается в браузере.

## Переезд со старого сайта

Для старых адресов WordPress (`/футбол/`, `/падел-теннис/`, `/новости/…`) созданы страницы-переадресации на новые разделы. Их список задан в `REDIRECTS` в `src/data.js`. Если хостинг позволяет, лучше настроить настоящий 301-редирект на сервере, например для nginx:

```nginx
location = /футбол/ { return 301 /football/; }
```
